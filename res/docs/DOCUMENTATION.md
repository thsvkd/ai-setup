# DOCUMENTATION

## 문서 지도

`AGENTS.md` 라우터가 가리키는 문서의 현재 상태다. 상태는 넷 중 하나다.

- `authoritative` — 확정된 계약. 코드와 어긋나면 둘 중 하나가 버그다.
- `draft` — 작성 중. 참고하되 확정 계약처럼 쓰지 않는다.
- `planned` — 파일이 아직 없다. 건너뛰고 `AGENTS.md` 의 기본 규칙을 따른다.
- `historical` — 당시의 결정 기록. 현재 동작의 근거가 아니다.

## 어디에 쓰는가

- 절차가 두 단계를 넘어가면 `AGENTS.md` 가 아니라 해당 문서에 쓴다. `AGENTS.md` 는 항상 컨텍스트에 올라가므로 얇게 유지한다.
- 라우터에 없는 문서를 만들지 않는다. 만들었다면 라우터와 위 표에 함께 등록한다.
- 등록만 하고 라우터가 가리키지 않는 문서는 아무도 읽지 않는다. 링크와 등록은 항상 같이 간다.

## 동기화

- 코드가 문서와 어긋나게 바뀌면 같은 작업 안에서 문서도 고친다. 다음 작업으로 미루지 않는다.
- **SSoT 문서(`PRD.md`·`SPEC.md`·`TEST_SPEC.md`)의 수정은 사용자 승인 후에만 한다.** 어긋남을 발견하면 고치지 말고 보고한다.
- 문서를 지우거나 상태를 바꾸면 라우터와 위 표를 함께 갱신한다.

## 쓰는 방식

- 각 줄은 "지우면 에이전트가 실수하는가"를 통과해야 남는다. 통과 못 하면 지운다.
- 같은 위반이 반복되면 규칙을 늘리지 말고 기존 규칙을 더 짧고 구체적으로 고친다.
- 예시는 하나면 충분하다. 두 번째 예시는 대개 첫 번째의 반복이다.
