잠긴 결정

  • 대상: Claude Code, Codex, Grok CLI. Gemini·IDE 챗창 제외.
  • 줄바꿈 키: 온보딩에서 Shift+Enter / Ctrl+Enter 중 선택. 기본·비대화형은 Shift+Enter.
  • Enter는 전송. 고르지 않은 수정 Enter는 건드리지 않음.
  • 전체 설치에 포함 + --keybinds. --hooks에는 안 넣음. 온보딩은 SCOPE=all일 때만 물음.
  • Linux 실측: 로컬 gnome-terminal이 아니라 SSH (WT/Cursor → linux-host). gnome-terminal은 경고만.
  • Grok은 키 리맵 불가 → 터미널 시퀀스에 의존. /multiline은 범위 밖(켜면 Enter↔Shift+Enter가 반대). 설치기는 그 토글을 건드리지 않고 경고만 한다.
  • 테스트 코드는 격리 HOME + APPDATA 픽스처만. 특정 SSH 호스트·실제 TUI 창은 Test-N이 아니다.

R3 실측 — 테스트 코드로 작성하지 않음

이 작업 환경(현재 Windows, ssh linux-host, ssh mac-host)에서만 가능한 확인이다. CI나 다른 개발 머신에서 실패하는 테스트가 되므로 Test-N이 아니다. R3 증거 번들로만 남긴다.

  • Windows Terminal + Claude / Codex / Grok: 고른 키 줄바꿈, Enter 전송
  • Cursor 통합 터미널 + 위 세 에이전트: 동일
  • SSH 원격 에이전트(linux-host, mac-host): 로컬 터미널에서 고른 키가 줄바꿈
  • Ctrl+Enter 선택 설치 후 세 에이전트에서 Ctrl+Enter 줄바꿈
  • Shift+Enter 선택 후 Grok Ctrl+Enter 기본 유지, Claude/Codex Ctrl+J 폴백 유지
  • Grok /multiline 켠 상태는 맞추지 않음 (키가 반대인 것이 정상)
